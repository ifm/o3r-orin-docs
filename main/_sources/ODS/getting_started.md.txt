# Getting started with ODS

Check out this video to get started with ODS:

Alternatively, you can read through the steps below.

## Prerequisites

- An OVP931 device (this comes with the required ODS app pre-installed),
- One or more O3R335 cameras,
- An Ethernet cable, FAKRA cable and power supply as specified in [the wiring instructions](../GettingStarted/index_getting_started.md#hardware-unboxing),
- The ifm Vision Assistant, which is the standard GUI from ifm used to interface with all 3D cameras (download the latest version on [ifm.com](https://www.ifm.com)).

## Step 0: Setup

Before wiring and calibrating the cameras, review the [ODS mounting recommendations](Mounting/mounting.md) and the [O3R335 clearance definition and illustrations](../IntegrationGuides/Mechanical/mechanical_guide.md#o3r335).

First, make sure to properly wire the O3R perception platform. You can follow [the wiring instructions](../GettingStarted/index_getting_started.md#hardware-unboxing).

Once the OVP93x and cameras are wired, open up the ifm Vision Assistant and make sure you can connect to the O3R platform and are able to receive data. 

## Step 1: Extrinsic calibration

### Quick start: enter an approximate camera pose

For a first look at the ODS occupancy grid, enter the approximate mounting position and orientation of each 3D camera in vehicle coordinates.
Do not use this estimate to evaluate detection performance.

1. In ifmVisionAssistant, open [manual calibration](../SoftwareInterfaces/iVA/manual_calibration.md) under **Port settings** and select the camera port.

   ```{image} img/open_iVA_calib_wizard.drawio.svg
   :alt: Open the manual calibration wizard in Port settings
   :width: 1080px
   :align: center
   ```

2. Select the orientation that matches the mounted camera and enter its offsets from the [vehicle coordinate origin](../IntegrationGuides/Mechanical/mechanical_guide.md#coordinate-systems).
   The example shows a level, forward-facing camera 50 cm above the floor.
   If the vehicle origin is at floor level, the vertical offset in this example is 0.50 m.
   Use the offsets for your installation.

   ```{image} img/calibrate_3D_cam.drawio.svg
   :alt: Manual calibration for a level, forward-facing 3D camera
   :width: 1080px
   :align: center
   ```

### Before performance testing or deployment

Calibrate each ODS camera in its final mounting position using one of the two calibration routines:

- Use [static camera calibration (SCC)](../CalibrationRoutines/SCC/README.md) with the vehicle and checkerboard stationary.
- Use the [motion camera calibration (MCC) wizard](../CalibrationRoutines/MCC/mcc_with_wizard.md) to calibrate during straight-line vehicle motion.

Use CAD values instead of SCC or MCC only if you have verified the actual camera position and orientation against the model and the mounting deviations are small enough for your application's accuracy requirements.

For operation on a moving vehicle, [calibrate the VPU](../CalibrationRoutines/OVPCalibration/README.md) as a separate step.
Use the same vehicle coordinate system as for the cameras so ODS can interpret motion measured by the VPU's IMU.

## Step 2: Create an ODS application

In the "Application" tab, create an ODS application instance.

```{image} img/create_ods_app.drawio.svg
:alt: Create an ODS application
:width: 1080px
:align: center
```
<!-- ![Create an ODS application](img/create_ods_app.png) -->

An application instance is created with default settings. By default, all connected 3D ports are added to the list of ports for the ODS app to use.

<!-- ![Default ODS application](img/default_ods_app.png) -->

```{image} img/default_ods_app.drawio.svg
:alt: Default ODS application
:width: 1080px
:align: center
```

:::{note}
When first instantiating the application, diagnostic messages may appear at the bottom of the screen. 
The ODS application performs some checks related to the motion of the vehicle, which may take some time to succeed while the application is running. Typically, these will disappear after the ODS has been able to initialize properly.
:::


## Step 3: Start ODS

To start ODS, you can simply set the `state` parameter to `"RUN"`:
<!-- ![Start the ODS applications. The occupancy grid appears.](img/start_ods.png) -->
<!--
```{image} img/start_ods.svg
:alt: Start the ODS applications
:width: 1080px
:align: center
```
-->
Once the application is running, objects identified as obstacles will appear in the occupancy grid.

You can also activate the default zones, by clicking on the "Set Example Zones" button:
<!-- ![Activate three example zones](img/zones.png) -->

```{image} img/zones.drawio.svg
:alt: Activate three example zones
:width: 1080px
:align: center
```
